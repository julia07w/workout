# WORK OUT

Фитнес-платформа на Next.js, React, TypeScript и Neon.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:3000`.

## Подключение Neon

1. Создайте проект в Neon Console и включите Neon Auth.
2. Скопируйте `.env.example` в `.env.local`.
3. Заполните `DATABASE_URL`, `NEON_AUTH_BASE_URL` и `NEON_AUTH_COOKIE_SECRET`. Секрет cookie должен содержать не менее 32 символов.
4. Откройте SQL Editor в Neon и выполните файл `db/schema.sql`.
5. Перезапустите сервер разработки.

Секреты из `.env.local` исключены из Git. Без этих переменных интерфейс собирается, но регистрация и сохранение данных не подключатся к облаку.

## Что хранится в базе

- аккаунт и сессия пользователя через Neon Auth;
- данные анкеты и цель тренировок;
- место, расписание и оборудование;
- история выполненных тренировок;
- заготовки для избранных тренировок и замеров тела.

API-маршруты `/api/profile` и `/api/progress` доступны только авторизованному пользователю.
